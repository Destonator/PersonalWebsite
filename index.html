Current project

Sailbot

Major Qualifying Project (MQP) at WPI, with two teammates

WPI's autonomous sailboat, the Wild Goats, competes in the International Robotic Sailing Regatta (SailBot), and our team's goal is to earn more points than last year's boat. It sails with a rigid wingsail on a freely rotating mast, with a trim tab that adjusts the sail to the wind.

We're upgrading three systems: navigation software that can tack and hold a steady heading, a computer vision model retrained to find buoys more reliably, and a compact circuit board (PCB) that regulates and monitors the sail's battery. Our targets are reaching any given point 90% of the time and identifying buoys with 80% accuracy.

  • Autonomous navigation
  • Computer vision
  • YOLO
  • PCB design
  • Team of three

Passion project

Minesweeper Bot

Built for fun

A bot that plays Google Minesweeper on its own. It takes a screenshot of the playing area and samples the color at the center of each tile, which tells it the number that tile holds.

The bot stores the board, runs a series of algorithms to work out which tiles are safe and which hide mines, then clicks the safe ones and repeats until the game is won. It comes as a Mac app, and the core bot.py script should run on any operating system from the terminal.

  • Python
  • Screen capture
  • Color sampling
  • Game-solving algorithms
  • Mac app

Mapping and Pathfinding Robot

RBE 3002 at WPI

We programmed a TurtleBot with ROS2 Jazzy, a Linux-based framework built for programming robots. Placed in an unknown environment, the robot explores until it has a complete map, then paths back to its starting position. It saves the map, and after a power-off it can localize itself from anywhere inside that map.

  • ROS2 Jazzy
  • TurtleBot
  • Autonomous mapping

Dartzilla

WPI class project with two teammates

The assignment was to engineer something around a hobby, so we built a dartboard that senses where darts land. Three cameras spaced evenly around the board see each dart from different angles, which lets the system triangulate its position and convert it to a score using the board's scoring grid. A Raspberry Pi hosts a web page with live scores, so the game shows up on a laptop on the far side of the room, safe from the darts.

  • Multi-camera triangulation
  • Raspberry Pi
  • Web interface

OpenX Manipulator Arm

WPI, junior year

My team programmed a 4-DOF robotic arm to detect, identify, and sort colored balls using MATLAB and image processing. We started with basic arm motion through the Dynamixel SDK on Ubuntu, then implemented forward and inverse kinematics, trajectory planning, and Jacobian-based velocity mapping for smooth, accurate movement. In the final lab we added camera mapping, filtering, and masking so the arm could find and sort objects across its workspace.

  • MATLAB
  • Dynamixel SDK
  • Inverse kinematics
  • Image processing

Gyroscope Xbox Controller

High school Electrical Engineering final project

Using an Arduino Leonardo, I built a controller that a computer recognizes as an Xbox controller. It has all the basics: joysticks, buttons, and triggers. I also added a gyroscopic mode that lets you steer like a wheel by tilting it, a feature the original controller lacked and one I thought would be both useful and fun.

  • Arduino Leonardo
  • Gyroscope
  • Controller emulation
